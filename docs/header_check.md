# FLAC header check

Generated by `python -m src.header_check fetch|report`. For 13 files, only the first 16,384 bytes were
fetched (HTTP `Range: bytes=0-16383`; every response was `206 Partial Content`). The FLAC STREAMINFO
block was parsed with `src/flac_header.py`. Raw results: `data/header_check.json`; each fetch's SHA-256 is in
`audit_log.jsonl`.

"Name estimate" is the duration `src/label_survey.py` assigns to the file from file names: the time to the
next file's start, capped at the normal file length. For the last file of a deployment there is no next file,
so it is file size ÷ the deployment's median bytes per second. "Mismatch" = |difference| > 2 s.

Vorbis comments contain only the encoder name; `riff` blocks hold only the original WAV RIFF/fmt/data headers. **UTC cannot be confirmed from the file metadata.** In 4 file(s) a SEEKTABLE runs past 16 KB, so any blocks after it were not inspected.
